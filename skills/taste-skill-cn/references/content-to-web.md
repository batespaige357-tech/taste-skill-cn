# 从中文材料到网页叙事

## 先建内容地图

原文是事实来源，不是可以任意改写的素材池。用简短的映射保留主要内容：

| 原材料 | 读者问题 | 网页表达 |
|---|---|---|
| 文章核心论点 | 为什么值得读？ | 标题、导语 |
| 具体经历与例证 | 凭什么相信？ | 段落、引用、带说明的图片 |
| 方法和步骤 | 我可以怎么做？ | 步骤或示例 |
| 活动事实 | 何时、何地、谁参加？ | 首屏附近的事实栏 |
| 报名或购买方式 | 下一步是什么？ | 有真实去向的行动入口 |

不要求每个页面具备所有行。保留用户的重要限定、争议、来源和语气；缺少证据就不添加“权威背书”。

## 三类常见材料

### 一篇长文章

保留阅读连续性。可以增加目录、引语和边注，但不能把论证压缩成三张卖点卡。摘要必须区别于原文；大幅删改先说明范围。图表仅用于有真实数据的关系。

### 一段活动介绍

先让读者找到主题、时间、地点、适合谁和参与方式。未知信息标记“待确认”；无报名目标时呈现清楚的状态文字，不制作一个看似可用的空链接。

### 一份产品或服务说明

用具体任务组织页面，如“把会议记录整理成行动项”，再展示输入与输出、限制、价格与行动。价格、服务承诺和用户评价只能来自已知信息。没有后端就明确演示性质。

## 改版时的证据

记录三到五处改变与理由即可：

- 之前：长标题在手机上破碎成六行。之后：删除空泛修饰，在语义停顿处组织成三行。
- 之前：活动时间隐藏在第三个区块。之后：移至标题下方的事实栏。
- 之前：每一段都是相同卡片。之后：正文连续阅读，只有需要比较的内容保留并列结构。

这些是待验证的效果描述；没有实际查看结果时不能写成已通过的视觉结论。
